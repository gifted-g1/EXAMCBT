Section A — Theory and Analytical Questions [40 marks]

Answer ALL questions in this section. Write concise, well-reasoned answers in the space provided. Where a question is open to more than one defensible answer, state your assumptions.

1.

A dynamic array doubles its capacity whenever it is full. Using amortised analysis, show that the cost of appending n elements is O(n) in total, so each append is O(1) amortised, even though a single append can cost O(n). Explain one practical reason some libraries grow by a factor of 1.5 instead of 2.

[3 marks]
2.

A 12-person engineering team maintains a single e-commerce application and proposes to split it into about 20 microservices. Compare this proposal with restructuring it as a modular monolith, considering deployment independence, data consistency, operational overhead and Conway's law. State your assumptions and recommend one option.

[4 marks]
3.

Distinguish between IT governance and IT management. Explain how a governance framework such as COBIT helps an organisation align IT investment with business objectives and measure the value delivered.

[3 marks]
4.

A university plans to replace its 15-year-old on-premises student records system with a cloud-based ERP platform within one academic year. Identify three significant risks of this digital transformation (technical, organisational or contractual) and propose a specific mitigation for each.

[4 marks]
5.

Compare link-state routing (for example OSPF) with distance-vector routing (for example RIP) in terms of convergence speed, scalability and resource use. Explain the count-to-infinity problem and how split horizon with poison reverse reduces it.

[3 marks]
6.

Define a Service Level Indicator (SLI), a Service Level Objective (SLO) and an error budget. Explain how an error budget policy can be used to balance release velocity against reliability, with a numerical example for a 99.9% monthly availability SLO.

[3 marks]
7.

Explain why passwords should be stored using a slow, salted, memory-hard function such as Argon2id or bcrypt rather than a single round of SHA-256. Discuss the roles of the salt and a pepper, and the economics of an offline attack after a database breach.

[3 marks]
8.

A bank's fraud-detection model reports 99% accuracy on a test set in which only 0.5% of transactions are fraudulent. Explain why accuracy is misleading here. Recommend more suitable evaluation metrics and describe how you would choose the decision threshold when a missed fraud costs far more than a false alarm.

[4 marks]
9.

Describe the dirty read, non-repeatable read and phantom read anomalies, and state which ANSI SQL isolation levels prevent each. Explain, with an example, why snapshot isolation still permits write skew.

[3 marks]
10.

Explain how a virtual address is translated to a physical address in a paged virtual-memory system with a Translation Lookaside Buffer (TLB). Show how the TLB hit ratio and page-fault rate affect the effective memory access time.

[3 marks]
11.

A battery-powered IoT soil sensor must report a reading every 10 minutes over an unreliable wireless link for at least two years. Compare a polling design with an interrupt-driven, deep-sleep design, and compare MQTT with HTTP for this device, in terms of energy use, reliability and security.

[4 marks]
12.

State the CAP theorem and explain how the PACELC formulation extends it. For a globally replicated online shopping-cart service, justify whether you would favour availability or consistency during a network partition, and what you would favour in normal operation.

[3 marks]

Section C — Applied Technical Problems [40 marks]

Answer ALL questions in this section. Each question carries 5 marks. Show your reasoning; marks are awarded for correct analysis and justified decisions, not only final answers.

23.

Consider the following function:

function fib(n):
    if n < 2: return n
    return fib(n - 1) + fib(n - 2)
  1. State its time complexity and explain why. (1 mark)
  2. Write pseudocode for a version that runs in O(n) time and O(1) extra space. (3 marks)
  3. Name one technique that computes fib(n) in O(log n) arithmetic operations. (1 mark)
[5 marks]
24.

An integration test passes on developers' machines but fails in about 10% of CI runs. The test creates an order, calls an endpoint that publishes an event asynchronously, and then immediately asserts that a notification row exists in a database shared by all CI jobs.

  1. Identify two likely causes of the flakiness. (2 marks)
  2. Describe how you would confirm each cause. (1 mark)
  3. Propose fixes to the test and the test environment that make it deterministic. (2 marks)
[5 marks]
25.

Staff at a branch office connected over a site-to-site VPN report two problems: (1) they can ping 8.8.8.8 but cannot open any website by name; (2) after the first problem is fixed, small web pages load but large downloads and some HTTPS sites stall.

  1. Explain a systematic diagnosis of problem (1), naming the tools or commands you would use. (2 marks)
  2. Explain the most likely cause of problem (2) and two ways to fix it. (3 marks)
[5 marks]
26.

A team deploys a stateless web service to production by running a single manual command from a laptop. Each release causes about two minutes of downtime, and a faulty release last month took an hour to roll back. Design a replacement delivery process.

  1. Outline the CI/CD pipeline stages, including how infrastructure is managed as code and how its state is stored safely. (2 marks)
  2. Choose blue-green or canary deployment and justify the choice. (1 mark)
  3. Explain how releases are rolled back automatically using monitoring signals. (2 marks)
[5 marks]
27.

A login handler contains the following code:

query = "SELECT * FROM users WHERE email = '" + email +
        "' AND password = '" + password + "'"
row = db.execute(query)
if row: create_session(row.id)
  1. Identify two security weaknesses and explain how each could be exploited. (2 marks)
  2. Rewrite the logic in pseudocode to remove both weaknesses. (2 marks)
  3. Name one additional control that limits online password-guessing attacks. (1 mark)
[5 marks]
28.

A machine-learning model used to pre-screen loan applications approves applicants from one demographic group at a markedly lower rate than others, and its precision has fallen steadily in the six months since deployment.

  1. Explain two fairness metrics you would compute and what each would reveal. (2 marks)
  2. Explain how you would detect and respond to data drift and concept drift. (2 marks)
  3. Describe one human-oversight mechanism appropriate for this decision. (1 mark)
[5 marks]
29.

A retailer has the tables Customers(customer_id, name, region) and Orders(order_id, customer_id, order_date, amount).

  1. Write an SQL query returning each region's total order amount for 2025, only for regions whose total exceeds 100000, highest first. (3 marks)
  2. Propose an index that would speed up the query and explain why. (1 mark)
  3. The table is loaded by a nightly pipeline that sometimes reruns after failures. Explain how to make the load idempotent. (1 mark)
[5 marks]
30.

A payment service consumes charge requests from a message queue that provides at-least-once delivery. Occasionally a customer is charged twice for one purchase.

  1. Explain how duplicate charges arise in this design. (1 mark)
  2. Design an idempotency mechanism that prevents them, stating where the idempotency key comes from and how it is stored. (2 marks)
  3. The service also publishes a 'payment completed' event after updating its database. Explain the dual-write problem and how the transactional outbox pattern solves it. (2 marks)
